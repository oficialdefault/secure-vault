# Secure Vault - Phase 1
This is the first project in my Python mastery journey. 

## Features
- **JWT Generation**: Uses `PyJWT` to create secure tokens.
- **Environment Safety**: Uses `.env` and `.gitignore` to protect secret keys.
- **Industry Standards**: Implements professional folder structures.

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Create a `.env` file with `MY_SUPER_SECRET_KEY`
3. Run `python auth_utils.py`
